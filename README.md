# Práctica de patrones de velas japonesas

Flashcards para reconocer los 7 patrones de la Fase 1 (martillo, gancho,
marubozu, doji, envolvente alcista, envolvente bajista, ninguno).

## Cómo abrirlo

Si tu navegador bloquea `fetch` sobre `file://` (pasa en Chrome), levanta
un servidor local trivial desde esta carpeta:

```
python3 -m http.server
```

y abre `http://localhost:8000` en el navegador.

## Progreso

Los aciertos e intentos se guardan en `localStorage`. El botón
"Reiniciar progreso" los borra.
